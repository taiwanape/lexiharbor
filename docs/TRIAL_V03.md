# 0.3 閱讀與自然語音試用

日期：2026-09-07。延續現有 Expo 專案、GitHub repo 與公開試用網址，不刪除既有詞庫收藏。這是一個可操作的新版試用，並非已完成可收費商業版。

## 本次完成

- 閱讀為主入口：貼上自己的文章，或選擇 3 篇本專案原創短文。
- 點字及首尾點選片語，保留精確原句、来源、自己的詞義與筆記；長片語有上限提示，不會使畫面閃退。
- 內建小樣有收錄時提供參考意思；未收錄時可自行填寫或主動開外部 Cambridge 查證。沒有爬取外部字典，也沒有假裝已自動翻譯全文。
- 原句字卡可搜尋、編輯、刪除與固定間隔複習；已有詞庫收藏及其複習保留在另外的分區。
- 閱讀資料獨立版本化保存；匯入整包驗證後合併，移除文章不刪字卡，衝突匯入不破壞既有資料。
- Web Locks 與寫入前比對避免不同分頁靜默覆寫；偵測衝突後保留本頁未存內容可匯出，要求重載，不自動復活刪除內容。
- 儲存失敗在彈出畫面內也看得見；可重試、匯出；離頁時對未完成儲存要求瀏覽器警告（瀏覽器是否顯示依平台限制）。
- 閱讀備份採兩槽輪替，相同匯入不持續占用空間。舊版詞庫備份格式仍獨立保留，並清楚標示不含閱讀。
- Kokoro 本機神經語音生成及網頁 WAV 播放；AI 音檔精確比對文字與語言，未命中明示裝置語音，不把機械聲冒充 AI。
- 音檔可停止、快速切換；過期播放事件不能覆寫新狀態。失敗顯示原因與重試提示。

## 驗證

- 93 項自動測試通過，包含閱讀領域 22、閱讀儲存 17、語音控制 16，以及既有功能測試。
- `pnpm typecheck` 與 `pnpm build:web` 通過。
- 390 × 844 網頁尺寸實測：新增自訂文章、選取 bank、填寫河岸意思、重複選字更新、單字本開啟、翻卡並安排 3 天複習、重新整理保留資料。
- 實測閱讀備份下載、錯誤 JSON 拒收、有效備份合併不重複加卡。
- 實测精選短文 AI 音檔在瀏覽器進入實際播放狀態並可停止；不是只驗證按鈕能按。
- 音檔完整性、WAV 格式、SHA-256、非靜音、長度與削波檢查使用 `tools/voice/verify.mjs`；清單會保存檢查數值。
- 共 106 個音檔：3 篇整文、23 個閱讀原句、79 個學習例句及 1 段試聽；19,904,264 bytes，414.575 秒。106 段來源文字完整覆蓋、125 個切句片段最長 168 tokens，另有 3 項 WAV 驗證器測試通過。以上不是人工聽感或發音正確性驗收。
- 兩個實際瀏覽器分頁驗證：先存的 A 文章保留，B 停止寫入且彈窗顯示衝突；重新載入不會被 B 覆蓋。另驗證移除測試文章後字卡、原句與複習仍保留。
- 公開 GitHub Pages 實測 AI 試聽完整播放；106 個遠端音檔 SHA-256 與本機一致，公開來源聲明正常回應。嵌入式瀏覽器缺少 URL 清理方法時，備份下載後也不會拋出未處理錯誤。

## 還沒完成，不能當作既有能力銷售

- 自訂文章目前不提供自動完整英漢翻譯；內建內容仍只有 60 个英文學習詞條及 489 筆漢英參考小樣。
- AI 覆蓋限美式精選原創短文與例句；單字、任意自訂文字、英式及原生 App 不保證有 AI 音檔，介面會明示來源。
- 音檔只完成機器訊號檢查，並未由人類英語編輯校聽。不能宣稱所有重音、同形異音或語調已驗收。
- 沒有登入、跨裝置自動同步、正式付款、訂閱權限、Android 簽章安裝檔或商店送審。帳號與金流實作前仍需要具體商業方案與使用者授權。
- 無 service worker，不能承諾離線重開網站；瀏覽器儲存額度有限。資料只在本機，需定期備份；不支援 Web Locks 的瀏覽器拒絕寫入並提示處理方式。
- 備份中同一筆資料若身分或原文真的衝突，會拒絕整包匯入並保留現有資料；尚未提供逐筆衝突編輯器。
- 內容編校、正式隱私與客服、付款與退款驗證、目標用戶留存與願付價格證據仍待完成。可公開試用不等於市場願意購買。

## 重製與發佈

一般開發只需根目錄依賴；網站載入已生成音檔，不需下載模型。

```bash
pnpm install --frozen-lockfile
pnpm test
pnpm typecheck
node tools/voice/verify.mjs
pnpm build:web
pnpm preview
```

`pnpm exec gh-pages --dotfiles --nojekyll -d dist` 發布到原本 GitHub Pages。正式上線後需驗證遠端 bundle、音檔與來源文件，並保留 source / gh-pages Git 歷史可回退。音檔重製另見 `tools/voice/README.md`，模型快取及生成器依賴不發布。
