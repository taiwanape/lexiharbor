# 0.2 詞庫試用版交付紀錄

更新：2026-09-07。此版是規劃階段 A 的資料研究交付與階段 B 的網頁流程實作；Android 安裝檔、正式內容准入與銷售發行尚未完成。

## 內容

- 60 個獨立編寫英文詞條：模型校閱、人工編校待完成。bank/run/take off 含不同常見義項和例句，went 可找到 go。
- 489 筆 CC-CEDICT 漢英小樣：439 個繁中詞，來源發布日期為 2026-09-06。完整授權、出處、checksum 和衍生資料公開於 `public/`。
- 300 個開發查詢已評估。漢英反查不適合直接作完整英漢字典；不宣稱語義正確率或完整覆蓋。詳見資料評估報告。

## 本次流程

查字、單字本、複習、設定四個入口；詳情共用。每日一字隨本地日期變更，收藏及歷史可開內容。評分記入實際到期時間，已排程的同字連點不重複計數。今日統計不在第 10 次歸零。

狀態以 v2 格式保存；遷移保留舊收藏和歷史，但不捏造 v1 沒有記錄的每日複習明細。所有狀態寫入經同一佇列；匯入先保留舊資料，阻擋並行變更，原始備份有匯出入口。格式錯誤的匯入遭拒且不改現有內容。

付費牆未連接到本版入口；不收費。語音依系統引擎，沒有假語音輸入或假每日提醒入口。

## 驗證證據

- 型別檢查通過；新增詞庫、搜尋、日期、複習、遷移與內容測試，既有 4 個歷史詞庫測試亦保留。
- 複習核心 16 項測試在預設、America/New_York、Pacific/Kiritimati 三種時區通過。
- 實際網頁操作已驗證：went→go；bank 兩個義項；收藏→單字本→詳情→複習；評為 3 天後重新載入仍有紀錄且不立即到期；匯出內容的 dueAt-reviewedAt 等於 259200000ms。
- 實際網頁操作已驗證：CC-CEDICT 蘋果詞條、出處頁、無效備份遭拒、有效備份還原、匯入前備份可匯出。
- 390×844 手機尺寸已視覺檢查，搜尋、卡片及底部分頁無水平溢位；正式 Android 系統行為仍須真機驗收。
- production Web export 通過；`dist/` 包含字型、資料來源、可下載漢英小樣與完整授權。此版沒有 service worker，不承諾網頁在首次載入後離線重開。
