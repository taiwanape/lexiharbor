# 有限查詢抽查與資料准入結論

本文件是開發代理依實際輸出進行的有限檢查，不是人工專業全審、盲測或統計語義正確率。489 筆原始詞條尚未逐義項通過正式編校；評估 JSON 的 semanticAccuracy 保留 null。

以下查詢來自已固定的 300 個開發查詢集；觀察對象是 `results.json` 的小樣＋明示詞形表結果。選擇案例是為了展示問題，不是計算抽樣準確度。

| 查詢 | 實際觀察 | 能／不能得出的結論 |
| --- | --- | --- |
| apple | 找到水果與科技公司的兩個「蘋果」詞條 | 基本名詞可反查，但同形詞沒有獨立英文義項頁；需呈現兩種內容的差異。 |
| bank | 候選是銀行、存款、河岸 | 金融機構與河岸都有相關詞，但存款是旁帶提及；候選不能全部當作 bank 的直接中文翻譯。 |
| run | 前四名為走、跑、跑步、經營 | 上游「走」保留較早用法；直接反查排序不適合作現代臺灣英語學習的主釋義。 |
| went | 明示映射成 go，候選含走、去，亦有送、放、穿 | 確有處理一個不規則詞形，但不是完整詞形分析，旁帶片語會造成噪音。 |
| take off | 候選為脫下與起飛 | 這兩個常見語境可找到；仍沒有整理成英文片語的義項結構及例句。 |
| 好奇 | 中文完全符合，提供原始拼音和英文解釋 | 符合漢英使用方向；此結果不能證明英文 curious 已有繁中學習釋義。 |
| saw | 映射為 see，首候選「大」來自交叉參照中使用 see 的提示 | 明確的檢索假陽性；saw 本身的名詞與動詞歧義也未解決。機械命中不等於語義命中。 |
| milk | 找到牛奶，英文解釋較具體地限定牛乳 | 對日常查詢有用，但 milk 的其他來源與動詞義尚未覆蓋。 |
| noodle | 小樣無候選 | 詞條中使用 noodles；單向查詢詞形表沒有索引側詞形處理，無結果不必然表示整個相關詞條不存在。 |
| bear | 候選為帶、坐；沒有動物熊 | 多義词只要找到任意旁帶義仍計命中，不能代表主要意思已涵蓋。 |
| case | 小樣無候選 | 小樣未收；全檔候選不等於已取得適合產品的釋義結構。 |
| spring | 找到泉、彈簧、春天 | 不同常見意思有候選，但排序與義項仍需英文學習用途的整理。 |

## 結論

資料來源、完整授權、固定版本和可重現的小樣研究流程已建立。資料適合標示為「CC-CEDICT 漢英研究小樣／英文反查相關詞」的受限內部試用。

「正式英漢主要義項已逐項檢查」的內容准入條件尚未完成。不得將本次機械結果用作收費完整英漢字典的準確率或覆蓋率宣稱；反查候選不宜直接轉成無提示的英文單字卡答案。

後續需分別處理交叉參照索引排除、英文義項整理、詞形歧義、臺灣用語與常見義項編校。這些列為已識別問題，本次未將其虛報為完成。
